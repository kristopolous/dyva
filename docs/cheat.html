DYVA Model Query Syntax

The model name is a query, not an exact id — the same grammar everywhere a model is named. A query selects a slice of the pool; dyva races the hosts that match.

Works in the model field of every endpoint (/v1/chat/completions, /api/chat, /api/generate), the chat model picker, the Server‑Room filter, and the map’s compare boxes. Everything is order‑free and composable. A query with no ; facet never touches the reputation DB.
Name Matching
nameContainment match, case‑insensitive. qwen → every qwen variant
* ?Globs: * any run, ? one char. qwen*27b, llama3?70b
*Alone — any model at all
name$End‑anchor: the exact name, skipping quant / finetune variants. qwen3.8:27b$
Containment vs. $. qwen3.8:27b also drafts in ‑q4_K_M and ‑abliterated; the trailing $ (the only regex metachar honoured) pins the end.
Fallback Chain
a,bTry a; only once it’s exhausted does b get a turn. Spaces optional. gemma3,qwen
…,*End a chain with * to guarantee a hit. !experimental,*
Comma is the separator because it’s shell‑safe and never appears in a model name.
Size Filters
>N <NDisk size, decimal (gb = 1e9). >10gb, <700mb
>=N <=NInclusive bounds. qwen <=4gb
unitskb mb gb tb — the b is optional
Keeps unknowns. Narrowing a name by size keeps candidates whose size the backend never reported; a bare >10gb returns only models known to satisfy it.
Date Filters
>YYYYRelease date, year precision. qwen>2026 = 2026 and newer
>YYYY-MMMonth precision. >2026-02
>=YYYY-MM-DDDay precision. >2026-02-15
Drops unknowns. Anything that can’t be placed in time is excluded. Missing parts default to 01 (2026 → 2026-01-01). Dates come from the bundled leaderboard.
Capability Pairing
cap/modelRequire a capability and a model. edit/wan, vision/qwen
Capabilities cap vocabulary
completion textPlain generation — always implied
vision imageCan see an attached image
toolsTool / function calls
audioAudio in / out
thinkingReasoning / think mode
Host Reputation Facets ;key op value
;tps>40Throughput — tokens/sec measured on the serving host
;ttft<0.5Time to first token (seconds)
;state=goodReputation tier — good, maybe_good, bad…
;fail_smoke=0Passed the smoke / honeypot screen
ops< > <= >= = on any whitelisted host_status column
Filters the host, not the model, and is the only thing that reads the reputation DB. Values are always bound, never interpolated; a thin DB simply returns little.
Capability Override ;caps=…
;caps=a,b;modelReplaces the caps dyva infers from the request with these exact ones
example;caps=text;qwen3 — attach an image for a tool yet route to a smart non‑vision model
Unlike reputation facets (which pick a host), this sets what the model must do. Blank or all‑unknown falls back to inference.
Meta Facets map view
;live ;deadLiveness
;cloud ;nocloudCloud vs. self‑hosted
;<service>By runtime. ;ollama, ;comfyui
;<provider>By hosting provider
Aliases !name — a pre-pass before the grammar
!nameA saved shortcut, substituted in place bash‑style before anything else is parsed — a trailing suffix rides along. !image-edit, !qwen>10gb
!fast→ qwen3,gemma3;state=good
!qwen>10gb→ qwen3.8>10gb  (when !qwen → qwen3.8)
!qwen*abliterated→ qwen3.8*abliterated
Define under Settings → Aliases, one block each (#comments and blank lines ignored; last definition of a name wins). Names are case‑insensitive. The ! fires only at a segment start (string start or right after a ,), so a ! inside a facet is untouched. An undefined alias matches nothing — end a chain with ,* to guarantee a hit.
How It Composes order-free & stackable

Grammar

query       = alternative ("," alternative)*
alternative = term (";" facet)*          ; order-free
term        = [ capability "/" ] name? predicate*
name        = text with * ? globs, opt. trailing $
predicate   = size | date
size        = (<|>|<=|>=) number unit
date        = (<|>|<=|>=) year [-month [-day]]
facet       = "caps=" cap ("," cap)*
            | key (<|>|<=|>=|=) value
            | live|dead|cloud|nocloud|service|provider

One valid query, read apart

;caps=vision;tps>100;qwen>2026-06>10gb
caps=visionrequire a model that can see
tps>100on a host measured above 100 tok/s
qwennamed qwen
>2026-06released after June 2026
>10gbat least 10 GB on disk

Order‑free, so qwen>2026-06>10gb;tps>100;caps=vision is the exact same query.
